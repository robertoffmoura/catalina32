### What's new

- **Portal** (Valve's Mac version from Steam). Catalina32 finds the Portal folder in your Steam
  library (or choose it, or drop it on the window: the folder holding `hl2_osx`) and makes
  *Portal.app*. Played from the first chamber to the ending. Settings and new saves go to
  `~/Library/Application Support/catalina32/Portal`; saves already in the game's folder still
  load, and the game's folder is never changed.
- **Faster.** The games' code is now translated to your Mac's own code as it runs (a JIT),
  instead of interpreted one instruction at a time: in testing, a busy LEGO Star Wars route ran
  2.2–2.5× faster.

### Known limits

- Portal's largest rooms (GLaDOS's chamber, the escape's big halls) run at a lower frame rate
  than the rest of the game, and the sound can skip briefly on the slowest frames.
- If the Portal folder moves (another Steam library), make the app again; saves made with
  Catalina32 before the move stay in `~/Library/Application Support/catalina32/Portal` but
  aren't seen by the new app yet.
- Apple Silicon hasn't been tested; the JIT is off there, so games run slower.
- Valve's other games (Half-Life 2 and its episodes) aren't supported yet.
